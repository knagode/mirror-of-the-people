# Slovenska nacionalna stranka (SNS) - Program

Vir: https://sns.si/program/

Programska vsebina ni dostopna za avtomatsko pridobivanje - spletna stran sns.si uporablja JavaScript za dinamično nalaganje vsebine (WordPress tema "Brooklyn"), zato vsebina programa ni vključena v začetni HTML.

Preizkušeni URL-ji:
- https://sns.si/program/ (vsebina se naloži dinamično z JavaScriptom)
- https://sns.si/programski-dokumenti/ (404)
- https://sns.si/volitve-2026/ (404)
- https://sns.si/o-stranki/ (vsebina se naloži dinamično z JavaScriptom)

Za pridobitev programa je potreben ročni obisk spletne strani in kopiranje vsebine.
